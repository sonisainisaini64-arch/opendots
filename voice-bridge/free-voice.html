🎙️ OpenDots Free Voice

Talk to any Dot by voice — free, and model-agnostic. Your browser does speech-to-text and text-to-speech for free (no key). The server only runs the Dot's normal chat turn, with whatever chat model is configured in OpenDots (Groq today, any OpenAI-compatible model tomorrow). This does not use OpenAI Realtime and does not need a paid voice key.

How it works, turn by turn: you speak → browser transcribes → text goes to the Dot → Dot replies in text → browser speaks the reply. It is push-to-talk, not a live duplex call — you speak, then the Dot speaks. No API key is in this page, and no key is ever sent from this page.

Use the URL where your OpenDots runs. If OpenDots runs on this same laptop, keep http://127.0.0.1:4310. If it runs on a remote VM, this page can only reach it through an HTTPS URL you have exposed for it — localhost on a VM is not reachable from your laptop browser.
